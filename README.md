# MindGit

MindGit 是一个面向深度阅读、技术调研和知识收集的 Chrome 浏览器扩展。它会把网页之间的跳转关系记录成可展开的树形脉络，帮助你回看“我是怎么一路找到这里的”。

当前版本：**v1.3.0**

## 介绍

当你在网页间跳转浏览时，MindGit 会自动记录这个过程，以树形结构展示出来，让你清晰地看到浏览的脉络。

## 功能

- **浏览脉络树**：自动记录主标签页中的页面跳转，按父子关系展示，并支持展开、折叠和拖拽整理。
- **会话管理**：为不同的阅读任务创建独立会话，支持自动命名、重命名、切换和删除。
- **记录开关**：在“设置 → 记录”中即时启用或停用网页记录。停用不会删除历史数据，重新启用后可继续记录。
- **搜索与定位**：按标题或 URL 搜索节点，并快速定位到对应记录。
- **两种视图**：树形视图和时间线视图，适配不同的回顾方式。
- **数据导出**：导出为 Markdown 或 HTML，保留树形结构。
- **GitHub Gist 同步**：可选的私有 Gist 同步，支持启动检查、手动上传、下载和冲突提示。
- **主题与界面**：支持浅色、深色及多种配色主题；弹窗针对高频操作做了紧凑化和低开销优化。

## 安装

### 使用 Release 安装

1. 下载 [MindGit v1.3.0](https://github.com/RumiaLunnar/mindGit/releases/tag/v1.3.0) 中的 `mindgit-v1.3.0.zip`。
2. 将 zip 解压到一个固定目录。
3. 在 Chrome 地址栏打开 `chrome://extensions/`。
4. 开启右上角的“开发者模式”。
5. 点击“加载已解压的扩展”，选择刚才解压的文件夹。

### 从源码安装

```bash
git clone https://github.com/RumiaLunnar/mindGit.git
cd mindGit
```

然后在 `chrome://extensions/` 中按上面的第 3～5 步加载项目目录。

## 使用说明

### 开始记录
安装后默认启用记录。浏览网页、点击链接或在单页应用中切换路由时，MindGit 会在当前会话中追加或更新节点。

如果暂时不希望记录新的页面，打开设置，点击“网页记录”右侧的“已启用”按钮即可停用。停用只影响后续捕获，不会清理已有会话。

### 管理会话
- 点击顶部的 `＋` 创建新会话。
- 点击会话列表中的项目切换当前会话。
- 使用会话项目上的重命名和删除操作管理历史会话。
- 使用底部的“全部展开”和“全部折叠”快速整理树视图。

### GitHub Gist 同步

1. 在 GitHub 创建一个具备 Gist 读写权限的 Personal Access Token（经典 Token 需要勾选 `gist` 权限）。
2. 打开 MindGit 设置中的“数据 → 云端同步”，配置并验证 Token。
3. 配置完成后，可以手动上传或下载；扩展也会在启动时检查云端是否有更新。

同步数据使用私有 Gist 保存。Token 仅保存在浏览器扩展的本地存储中，不会写入同步文件；不需要同步时可以不配置 Token。

## 快捷键

### 全局操作
| 快捷键 | 功能 |
|---------|------|
| `/` 或 `Ctrl+K` | 打开搜索 |
| `?` | 显示快捷键帮助 |
| `N` | 新建会话 |
| `S` | 打开设置 |
| `Esc` | 关闭弹窗 |

### 节点导航
| 快捷键 | 功能 |
|---------|------|
| `↑` / `K` | 上一个节点 |
| `↓` / `J` | 下一个节点 |
| `←` / `H` | 折叠节点 |
| `→` / `L` | 展开节点 |
| `Enter` | 打开节点链接 |

### 批量操作
| 快捷键 | 功能 |
|---------|------|
| `E` | 展开所有节点 |
| `C` | 折叠所有节点 |

## 开发

项目是原生 Manifest V3 扩展，不需要打包器运行。需要 Node.js 18+ 以及可用的 `zip` 命令；在 Windows 上打包脚本会自动回退到 PowerShell 的 `Compress-Archive`。

```bash
npm install
npm run build
npm run package
```

- `npm run build`：检查 Manifest V3 入口和所有 JavaScript 文件语法。
- `npm run package`：生成 `mindgit-v1.3.0.zip`，可直接用于发布 Release。

## 权限与隐私

MindGit 使用以下 Chrome 权限完成记录功能：

- `tabs`：读取标签页的标题、URL 和网站图标。
- `webNavigation`：监听主框架导航和单页应用路由变化。
- `storage`：保存本地会话、设置和可选的同步配置。
- `<all_urls>`：允许在不同网站之间统一捕获导航事件。

浏览记录默认只保存在本地浏览器中。只有在配置 GitHub Token 并主动使用同步功能后，数据才会上传到你的私有 Gist。
