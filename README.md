# MindGit

类似思维导图的浏览记录工具，追踪和可视化网页跳转路径。

## 介绍

当你在网页间跳转浏览时，MindGit 会自动记录这个过程，以树形结构展示出来，让你清晰地看到浏览的脉络。适合深度阅读、技术调研、知识收集等场景。

## 功能

**🌳 树形可视化**
- 自动记录页面跳转关系，生成树形结构
- 支持展开/折叠节点，聚焦关键内容
- 不同深度节点使用不同颜色区分
- 拖拽排序，自由调整节点位置

**📁 会话管理**
- 多个独立会话，分离不同任务
- 会话列表可折叠，节省空间
- 自动命名和自定义名称
- 支持重命名和删除

**☁️ 云端同步**
- 通过 GitHub Gist 实现多设备同步
- 启动时自动检查云端更新
- 一键手动同步
- 数据冲突提示

**🔍 搜索定位**
- 快捷键 `/` 或 `Ctrl+K` 呼出搜索
- 支持按标题、URL 搜索
- 搜索结果高亮定位

**📊 视图模式**
- 树形视图：层级化展示跳转关系
- 时间线视图：按日期分组查看历史

**📤 数据导出**
- 导出为 Markdown（笔记软件友好）
- 导出为 HTML（可用浏览器打开）
- 保留树形结构

**🌙 主题切换**
- 支持浅色/深色模式
- 多种配色方案
- 一键切换

## 安装

1. 下载 [mindgit-v1.3.tar.gz](https://github.com/RumiaLunnar/mindGit/releases/tag/v1.3)
2. 解压文件
3. Chrome 访问 `chrome://extensions/`
4. 开启右上角"开发者模式"
5. 点击"加载已解压的扩展"，选择解压后的文件夹

## 使用说明

### 开始记录
安装后自动开始记录浏览，无需手动操作。点击页面中的链接，会自动记录跳转关系。

### 管理会话
- 点击顶部 `➕` 创建新会话
- 点击左侧会话名切换会话
- 右键点击会话可重命名或删除

### 云端同步配置
1. 访问 GitHub Settings → Developer settings → Personal access tokens
2. 生成新 token，勾选 `gist` 权限
3. 在 MindGit 设置面板输入 token
4. 点击顶部☁️ 按钮手动同步，或等待启动时自动检查

## 快捷键

### 全局操作
| 快捷键 | 功能 |
|---------|------|
| `/` 或 `Ctrl+K` | 打开搜索 |
| `?` | 显示快捷键帮助 |
| `N` | 新建会话 |
| `S` | 打开设置 |
| `Esc` | 关闭弹窗 |

### 节点导航
| 快捷键 | 功能 |
|---------|------|
| `↑` / `K` | 上一个节点 |
| `↓` / `J` | 下一个节点 |
| `←` / `H` | 折叠节点 |
| `→` / `L` | 展开节点 |
| `Enter` | 打开节点链接 |

### 批量操作
| 快捷键 | 功能 |
|---------|------|
| `E` | 展开所有节点 |
| `C` | 折叠所有节点 |
